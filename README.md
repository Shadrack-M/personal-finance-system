# Web-Based Personal Finance Management System

A web application that helps students and young adults 
track income, expenses, budgets, and savings goals.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Database:** MySQL

## Features
- Secure user registration and login
- Record income and expense transactions
- Monthly budget management with progress tracking
- Savings goals with fund tracking
- Visual reports and charts
- Responsive design

## How to Run
1. Install dependencies:
   pip install flask mysql-connector-python werkzeug

2. Start MySQL in XAMPP

3. Run the app:
   python app.py

4. Open browser at:
   http://localhost:5000
